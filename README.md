# Battle of Banmo — วิธีเข้าเล่น

เกมการ์ด 1v1 แบบพิกเซล 9 เผ่า เล่นบนเว็บ ไม่ต้องติดตั้ง ไม่ต้องสมัคร

**เข้าเล่น: https://jomtup111.github.io/card-game/**

## สิ่งที่ต้องมี

- มือถือหรือคอมที่มีเบราว์เซอร์รุ่นใหม่ (Chrome, Safari, Edge, Brave, Firefox)
- เน็ต: ต้องใช้ตอนเปิดเว็บครั้งแรกและตอนเล่นกับเพื่อน · ถ้าติดตั้งเป็นแอปแล้ว เล่นกับบอทได้แม้ไม่มีเน็ต
- เล่นกับเพื่อน: ทั้งสองคนต้องต่อเน็ตพร้อมกัน

## เริ่มเล่นครั้งแรก

1. เปิดลิงก์ข้างบน แตะหน้าโลโก้
2. พิมพ์ชื่อของคุณช่อง **ผู้เล่น** มุมซ้ายบน (เพื่อนจะเห็นชื่อนี้)
3. ยังไม่เคยเล่น: กด **? สอนเล่น** (9 ขั้น) แล้วลอง **✦ ฝึกเล่น** ซึ่งมีคำแนะนำระหว่างเล่น
4. เลือกเดคในกล่องด้านขวา: เลือก "สาย" ได้เลย (ระบบจัดเดค 50 ใบให้อัตโนมัติ) หรือจัดเองที่ **▤ จัดเดค**

## เล่นกับบอท

กด **⚔ เล่นกับบอท** → เลือกความยาก (ง่าย / ปกติ / ยาก) → **เริ่มเล่น**

## เล่นกับเพื่อน (ออนไลน์)

**คนสร้างห้อง**
1. กด **☺ เล่นกับเพื่อน** → เลือกเดค → เลือก **เวลาต่อเทิร์น** (45 วิ / 75 วิ / 2 นาที / ไม่จำกัด) → **สร้างห้อง**
   - หมดเวลา = จบเทิร์นให้อัตโนมัติ · ตอนอีกฝ่ายกำลังเลือกเวทสวนหรือเลือกการ์ดที่จะทิ้ง เวลาของเราหยุดเดิน
   - เลือกตอนตาอีกฝ่าย (เวทสวน / ถูกสั่งให้ทิ้งการ์ด) มีเวลา 20 วิ หมดแล้ว = ไม่ตอบโต้ / เกมเลือกให้
2. ส่งห้องให้เพื่อน: **คัดลอกลิงก์**, **LINE**, **แชร์** (มือถือ) หรือให้เพื่อนสแกน **QR** บนจอ
3. รอเพื่อนเข้า เกมเริ่มเอง

**คนเข้าห้อง**
- กดลิงก์หรือสแกน QR ที่เพื่อนส่งมา → เลือกเดค → **เข้าห้อง**
- หรือเปิดเว็บเอง → **☺ เล่นกับเพื่อน** → ใส่ **รหัสห้อง 5 ตัว** → **เข้าห้อง**

จบเกมแล้วกด **พร้อมเล่นอีกตา** (เปลี่ยนเดคได้) เล่นต่อในห้องเดิม

## ดูเพื่อนเล่น

ใส่รหัสห้องแล้วกด **👀 ดู** หรือขอ "ลิงก์ดู" จากคนสร้างห้อง (ปุ่ม **คัดลอกลิงก์ดู**)
ผู้ชมเห็นกระดานแต่ไม่เห็นการ์ดในมือ และกดอะไรไม่ได้ · ดูได้พร้อมกันสูงสุด 4 คน

## แชร์เดคให้เพื่อน

**▤ จัดเดค** → เปิดเดค → **📤 แชร์เดค** → ส่งลิงก์ / LINE / QR
เพื่อนกดลิงก์จะเห็นตัวอย่างเดค แล้วกด **บันทึกเดค** (ไม่ทับเดคเดิม)

## สถิติกับเพื่อน

**☺ เล่นกับเพื่อน** → **📊 สถิติกับเพื่อน**: ชนะ–แพ้กับแต่ละคน ชนะเร็วสุด เดคที่ใช้บ่อย
นับเฉพาะเกมที่เล่นจนจบ · เก็บในเครื่องของแต่ละคน (ล้างข้อมูลเบราว์เซอร์ = หาย)

## ติดตั้งเป็นแอป (ไม่บังคับ)

- **iPhone / iPad (Safari):** ปุ่มแชร์ ⬆ → **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** เมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**
- **คอม (Chrome / Edge):** ไอคอนติดตั้งท้ายช่องที่อยู่เว็บ หรือปุ่ม **📲 ติดตั้งเป็นแอป** ในหน้าแรก

เปิดแอปครั้งแรกตอนมีเน็ต ระบบจะโหลดรูปการ์ดทั้งหมดเก็บไว้ หลังจากนั้นเล่นกับบอทแบบไม่มีเน็ตได้

## ควบคุม

- **มือถือ:** แตะการ์ดเพื่อเลือก ลากการ์ดขึ้นสนาม ลากมอนสเตอร์ไปหาเป้าเพื่อโจมตี · ปุ่มเมนู ☰ มุมขวาบน
- **คอม:** คลิกหรือลากแบบเดียวกัน · ปุ่มลัด `1`–`9` เลือกการ์ดในมือ · `Enter` ยืนยัน (มือเริ่มต้น / อัญเชิญ) · `Space` จบเทิร์น · `Esc` หรือคลิกขวา ยกเลิก
- **สกิลที่ต้องเลือก:** สกิลที่เลือกเป้าได้ (ทำลาย / ยึด / แช่แข็ง / บัฟ / สังเวย ฯลฯ) ให้แตะมอนสเตอร์ที่ขอบเรืองแสงบนสนาม · สกิลที่ทิ้งหรือหยิบการ์ด (ทิ้ง N ใบ / ค้นหาจากเดค / ชุบจากสุสาน / จ่าย gem ปลุกมังกร) จะเปิดหน้าต่างให้แตะเลือกการ์ด แล้วกดยืนยัน
- **สุสาน / ปลุกมังกร:** แตะกองสุสาน (ข้างกองเดค) เพื่อดูการ์ดในสุสานทั้งของเราและศัตรู · ถ้ามี 🐉 กระพริบ = มีมังกรหลับใหลพร้อมตื่น · ต้นเทิร์นเกมจะถามว่าจะปลุกตัวไหน (ไม่ปลุกก็ได้)
- **ปุ่มมุมขวาบน:** 📜 บันทึกเกม · 🔊 เสียง · 🐞 รายงานบัค · ⚙ ตั้งค่า (ความเร็วอนิเมชัน เสียง เพลง คำแนะนำ) · ⏏ ออก
